Sistema de gestion de estudiantes 
este proyecto ha sido desarrollado con html, php , css, javascript y mysql

1. descaragar este repositorio 
2. colocamos la carpeta en el directorio de "htdocs" en xampp
3. Importar la base de datos utilizando el archivo ubicado en la carpeta `database/` esta base se llama estudiantes y la tabla se llama personal en caso que tengas que crearla tu 
4. Abrir en el navegador: `http://localhost/sistema-estudiante/`
